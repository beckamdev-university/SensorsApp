# SensorsApp

Aplicación desarrollada con **Expo** como parte de una actividad universitaria.

## Tecnologías

- React Native
- Expo SDK 58
- JavaScript
- npm

## Requisitos

- [Node.js](https://nodejs.org/)
- npm
- [Expo Go](https://expo.dev/go) (opcional, para ejecutar la aplicación en un dispositivo móvil)

## Instalación

Clona el repositorio y accede al directorio del proyecto:

```bash
git clone <URL_DEL_REPOSITORIO>
cd SensorsApp
```

Instala las dependencias necesarias:

```bash
npm install
```

## Ejecución

Inicia el servidor de desarrollo de Expo:

```bash
npx expo start
```

Una vez iniciado el servidor, puedes:

- Escanear el código QR con Expo Go para ejecutar la aplicación en tu dispositivo móvil.
- Presionar `a` para abrir la aplicación en un emulador de Android.
- Presionar `i` para abrir la aplicación en el simulador de iOS (requiere macOS).

## Notas

- El proyecto utiliza Expo SDK 58.
- Se recomienda mantener el dispositivo móvil y el ordenador conectados a la misma red Wi-Fi al utilizar Expo Go.
- Si aparecen problemas con las dependencias, ejecuta nuevamente `npm install`.
